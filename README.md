# Off-Night-Optimizer

Off-Night Optimizer is a personal iOS app for my Yahoo Fantasy Hockey league. Each matchup week, it compares my roster's eligible positions and the NHL schedule against my league's active lineup slots, finds the days I'll have an empty active slot, and ranks available free agents by how many of those empty slots they'd fill.

Data needed (read-only): league settings (roster positions, scoring type, weekly add limits), my team's roster with eligible positions, the free agent and waiver player list with eligible positions, NHL team, and basic stats.

Users: myself, and possibly the other managers in my league (about 12 people) through TestFlight. No public App Store release is planned right now.

Data handling: all data stays on the user's device. There is no backend server, no data sharing, no ads, and no resale. Read-only access is enough. The app will show "Fantasy data provided by Yahoo Fantasy" as required.
